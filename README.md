# Real-Time Chat Application

A real-time chat application developed using React.js, Node.js, Express.js, Socket.IO, and MySQL.

## About the Project

This project allows users to communicate with each other through real-time messaging. It includes user authentication and message management features.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- Socket.IO

### Database
- MySQL

### Authentication
- JSON Web Token (JWT)

### Tools
- Visual Studio Code
- Git and GitHub

## Features
- User Registration
- User Login
- User Authentication
- Real-Time Messaging
- Chat History
- Message Status Tracking
